## What these numbers do not cover

- **One model, one language, one day.** Everything above is `deepseek/deepseek-v4-flash` on English. Change the model id and the moderate/low boundary moves; the high boundary is protected by the floor, not by the model.
- **A corpus written by the same person as the rules.** Broad enough to be useful, small enough to overfit. Real check-ins are longer, ungrammatical, and code-switched.
- **Nothing about transcription.** A clip that transcribes badly changes what the floor can see at all; that has to be measured with real audio.
- **2 under-classification(s) in this run** ("I snapped at my kids and then sat in the car for" → low; "Feeling lonely since I moved cities" → low). All are moderate→low: no high item was ever reported below high. These read as labelling judgement as much as model error.
- **Run to run this moves.** Temperature is 0.1, not 0: repeated runs on the same corpus have differed by one or two moderate/low judgements. The high row has been 19/19 on every run so far, which is the invariant worth watching.
- **Alerting, not detection.** This measures the risk label. Whether a clinician actually sees it in time is a workflow question this corpus says nothing about.
